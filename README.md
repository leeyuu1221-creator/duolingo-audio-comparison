# Duolingo multilingual audio comparison

8 languages × 3 random samples × 5 versions = 120 unmodified WAV files.

Open `index.html` directly, or run `python3 -m http.server 8000` in this folder.

## GitHub Pages
Upload this folder's contents to a public GitHub repository (repository root).
In Settings → Pages choose Deploy from a branch → main → / (root) → Save.
The public address will be https://leeyuu1221-creator.github.io/duolingo-audio-comparison/ if the repository is named duolingo-audio-comparison.

Seed: 20261111. Originals sampled from the complete sorted 16 kHz test WAV lists; reconstructed files matched by exact filename. Original files are unchanged; no normalization or transcoding. See samples.json for sample IDs, paths and metadata.

Added FocalCodec 162 bps and 325 bps using the same 24 sample IDs. All WAV files copied without modification.
